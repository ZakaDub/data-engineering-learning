# Week 1: Core Diagnostics

Initial practice week to verify SQL and Python (Pandas) fundamentals and establish the project repository structure.

## Covered Topics
- **SQL**: `LEFT JOIN`, `GROUP BY`, `COALESCE`, and window functions (`ROW_NUMBER` with `PARTITION BY` / `ORDER BY`).
- **Python / Pandas**: File I/O (`pd.read_csv`), missing value checks (`isna`), data sorting (`sort_values`), and top-N extraction (`head`).
- **Tooling**: Git project initialization and basic workflow.
